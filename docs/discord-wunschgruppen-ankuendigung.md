# 👥 Aus Wunschduos werden Wunschgruppen!

@everyone

Für das **Ultimate-Bravery-Turnier** erweitern wir das bisherige Wunschduo-System: Ab sofort könnt ihr eine **Wunschgruppe mit bis zu fünf Personen** bilden.

## So funktioniert es

- Besucht <https://tournament.lauchgruen.de/me>.
- Eine Person erstellt im Bereich **Wunschgruppe** einen privaten Code.
- Teilt diesen Code mit den Personen, mit denen ihr gerne zusammenspielen möchtet.
- Die anderen Personen können den Code auf derselben Seite eingeben und der Gruppe beitreten.
- Eine Wunschgruppe kann aus **einer bis fünf Personen** bestehen.

Bereits erstellte Wunschduo-Codes bleiben gültig. Ihr müsst keine neue Gruppe anlegen und könnt eure bestehende Gruppe einfach auf bis zu fünf Personen erweitern.

## Wichtig zur Team-Balance

Eine Wunschgruppe ist weiterhin **ein Wunsch und keine Garantie**, dass alle Mitglieder im selben Team landen. Wir versuchen, eure Gruppen bei der Teamerstellung bestmöglich zu berücksichtigen, behalten uns aber vor, sie aus Fairness- und Balancing-Gründen teilweise oder vollständig aufzuteilen.

Bitte diskutiert im Nachhinein nicht mit der Orga, falls eine Wunschgruppe für eine faire Teamverteilung getrennt werden muss. Mit dem Beitritt bestätigt ihr weiterhin, dass ihr diese Bedingung verstanden habt.

Wenn ihr bereits wisst, mit wem ihr gerne spielen möchtet, besucht jetzt eure Account-Seite und erstellt eine Wunschgruppe oder tretet einer bestehenden bei:

👉 <https://tournament.lauchgruen.de/me>
